# ⭐ Les Étoiles de Taounate — V4 Pro

Application PWA hors ligne pour la gestion d'une école sportive de football.

## Mise en ligne GitHub Pages
1. Créer/remplacer le contenu d'un dépôt GitHub avec tous les fichiers de ce dossier.
2. Activer GitHub Pages sur la branche principale, dossier `/root`.
3. Ouvrir l'URL HTTPS sur Android.
4. Utiliser le bouton **Installer**.

## Fonctionnalités
- 128 adhérents importés depuis le fichier Excel fourni.
- Gestion adhérents : ajout, modification, suppression, recherche et filtres.
- Espace entraîneur : séances, présences et évaluations.
- Cotisations et suivi des paiements.
- Matchs et résultats.
- Tableau de bord et statistiques.
- Sauvegarde/restauration JSON.
- Fonctionnement hors ligne via Service Worker + localStorage.
- Installation PWA sur Android.

## Données source
Les noms et données disponibles dans le fichier Excel fourni sont importés tels quels. Les champs absents restent vides.
